المتطلبات الوظيفية والتقنية:
1. محرك بحث معاملات SAP المصوّر بالأسهم والترقيم (Interactive T-Code Visual Explorer):
   - شريط وصول سريع للشاشات العشر الحقيقية المرفقة من نظام SAP GUI (sapps4app009):
     * LS24 (20261019_231146.jpg): Stock per Material (Warehouse Number, Material, Plant, Storage Type/Bin, List View/ALV Grid).
     * VT01N (20261019_231230.jpg): Create Shipment Initial Screen (TransportPlanningPt = TAC2 Logistics shipp, Shipment Type, Deliveries button).
     * VL06C (20261019_231305.jpg): Outbound Deliveries for Confirmation (Confirm in Background, Pland Gds Mvmnt Date).
     * VL06P (20261019_231339.jpg): Outbound Deliveries for Picking (Create TO in Background, Both Picking Types, Check at Item Level).
     * VL06O (20261019_231359.jpg): Outbound Delivery Monitor (8 yellow buttons: For Checking, Distribution, Picking, Confirmation, Loading, Goods Issue, Transport Planning, List Outbound Deliveries).
     * ZPACKCONF (20261019_231429.jpg): Packing Cockpit (Shipment Status 1..7, CSL Label verification, Auto-pack, ZPRN, RF Box/Pallet Packing, Pack by 3S, Load HU).
     * ZMM4TR093 (20261019_231448.jpg): Warehouse Picking Performance Report (TO Confirmation Date, License Tag 3S/4S, User ID).
     * MB51 (20261019_231533.jpg): Material Document List (Movement Type, Posting Date, Layout /DEFAULT+BC).
     * ZMM4TR021 (20261019_231507.jpg): License Tag Report (Carton/Pallet/Shipment LT, Country of Origin, c:\ZLICTAG1.xls, ZINCUSTOMS).
     * MB52 (20261019_231606.jpg): Display Warehouse Stocks of Material (Display Batch Stocks, No zero stock lines).
   - بالإضافة إلى معاملات التصدير والإمداد: VA01, VL01N, VL02N (PGI 601), VL09 (602), VT02N, VF01 (Proforma F8), LT03, HU02, /SCWM/PRDO, /SCWM/PACK, /SCWM/TU, ME21N, MIGO, QA32, CO15, MMBE.
2. خريطة رحلة المخزون الشاملة من الإنتاج إلى التصدير (8 مراحل متكاملة) مع تتبع تحول حالة المخزون وأكواد الحركة (Movement Types: 101, 321, 311, 261, 601, 602).
3. استوديو تفاعلي لرفع صور SAP الحقيقية وترقيمها بالأسهم وتوليد JSON للنشر المباشر على GitHub.

خطوات النشر المجاني على GitHub Pages مع صورك العشر:

  1. أنشئ مستودعاً جديداً (Repository) على حسابك في GitHub.
  2. ارفع هذا الملف باسم index.html وارفع بجانبه الصور العشر بنفس أسمائها الأصلية (20261019_231146.jpg إلى 20261019_231606.jpg).
  3. من تبويب Settings → Pages اختر الفرع main ثم اضغط Save ليصبح موقعك متاحاً للجميع.

تحويل الموقع إلى تطبيق Android (PWA / APK):

  1. تثبيت مباشر (PWA): افتح رابط GitHub Pages من متصفح Chrome على هاتفك الأندرويد واضغط "الإضافة إلى الشاشة الرئيسية / Install App".
  2. ملف APK مستقل: ضع رابط موقعك على GitHub Pages داخل موقع PWABuilder.com واضغط Package for Stores → Android APK لتنزيل ملف APK جاهز للتثبيت.
